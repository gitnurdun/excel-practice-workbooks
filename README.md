# Excel Practice Workbooks

100 self-contained Excel practice workbooks and a central [INDEX.xlsx](INDEX.xlsx) for navigating the collection.

## Start here

1. Clone or download this repository.
2. Open `INDEX.xlsx` in Microsoft Excel to choose an exercise.
3. Open the corresponding `challenge_*.xlsx` workbook and follow its instructions.
4. Work in a copy if you want to preserve the original exercise.

```sh
git clone https://github.com/gitnurdun/excel-practice-workbooks.git
```

## Files

| File | Purpose |
| --- | --- |
| `INDEX.xlsx` | Workbook index |
| `challenge_01.xlsx` through the numbered collection | Individual exercises |

Filenames intentionally retain their existing numbering, including the three-digit names beginning at `challenge_061.xlsx`. No scripts, packages, or build steps are required to use the workbooks. Spreadsheet features may behave differently in applications other than Microsoft Excel.
